# 独立监视屏专用主题

在设置 → 独立监视屏 → 导入主题中选择 `sage.json`，先查看预览，再点击应用。

独立监视屏主题只接受此目录示例的 JSON 格式，不接受桌面的 `.aidetheme` Widget 包。
320×170 为主题文件的设计基准，展示时自适应屏幕，竖屏四平台自动排列为两行。`layout` 可选 `rows`（账号列表）或 `columns`（四平台）。
`palette` 必须包含示例中的五个六位十六进制颜色。ID 以 `usb-custom-` 开头，使用小写字母、数字和连字符。
导入时保存至本机设置，不执行脚本。最多 20 个主题，每个文件不超过 32 KB。
