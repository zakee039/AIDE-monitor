# v0.7.0

- 账号设置新增「额度池」多选列。Antigravity 可选择 Gemini 3、Claude、Gemini 4；每个选中池作为一个展示项，默认名称为「账号名-池名」。
- 桌面、独立监视屏、分页、推荐与四平台账号计数统一使用展示项；同一账号的池仍共享登录凭据、代理、刷新间隔和一次网络查询。
- Gemini 4 Argon 读取 `gemini-argon-wtu-weekly`，只展示周额度；接口未返回时显示未知，不用其他池数据补齐。
- Grok 展示共享额度池，支持共享池字段、周/月周期和旧月度额度结构；产品用量占比与购买余额不拆成独立展示项。请求版本更新为 1.0.52。
- Antigravity 企业接口要求有效项目，排除个人账号占位项目与孤立 GCP 标记。
- 总额度沿用 `quota_total::calculate`，按平台汇总选中的展示项，继承原账号的订阅换算设置。不同池的折算仍为本地估算，不代表服务商允许跨池使用。
- 原有设置默认保留 Antigravity 的 Gemini 3 池和 Grok 共享池。最多 100 个展示项，额度池选择随本地设置保存。

API：`accounts.selection.update` 增加可选 `accountPools: Record<AccountId, string[]>`，`settings.get` 返回保存的选择；`accounts.list` 仍返回登录账号，`quota.snapshot.get` 返回拆分后的展示项。展示项 ID 为宿主生成的稳定标识；刷新支持展示项 ID，并在服务端归并到原账号。
