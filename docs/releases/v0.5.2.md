# AIDE monitor 0.5.2

圆形悬浮窗现在可以独立累计 ChatGPT、Claude、Antigravity 或 Grok 的剩余额度。平台选择只显示已经添加账号的平台，累计范围为该平台中已勾选的账号，恢复倒计时也跟随该平台。

- 有 5h 限制的账号：5h 剩余低于 5% 或周额度低于 2% 时不计入；其余账号以 5h 余额和周额度实际可支持的余额两者中的较小值累计。
- 支持纯 5h、纯周额度及混合账号，也支持按订阅倍率换算到基础订阅单位。
- “窗口与显示”从常规页移为独立设置页，放在常规下方。新增“悬浮窗额度显示”和可展开的“订阅额度换算”，可以指定每个账号的订阅档位或自定义倍率及比例。
- 缩窄账号表的代理、自动刷新两列；设置窗口默认宽度增加 20 逻辑像素至 740。
- 额度数据失败、过期、超过重置时间或无法识别时不伪造余额。未返回订阅信息时会注明按基础档估算，已返回但无法识别的订阅档位可手动指定。

暂定换算比例：ChatGPT 15%；Claude Pro 15%、Max 5x 10%、Max 20x 20%；Antigravity Pro / Ultra 25%（Ultra 为占位值）。这些比例为应用估算，可以调整，不是官方保证。Antigravity 使用 Gemini 额度池，Grok 高级档位需自定义倍率；本版不采用尚未确认的 Xpass 档位。

Windows x64 下载包含独立运行 EXE、安装包、便携 ZIP 和 SHA-256 校验文件。便携版及独立运行版需要系统已安装 WebView2。所有本地发布产物统一放在 `artifacts/release-v0.5.2/`。
