# v0.7.3（本机测试版）

- 所有额度池统一从真实 5h／7d 消耗变化学习比例，取消固定比例；回溯最近满足 50 个百分点降幅的样本，允许绝对 ±2.1 个百分点偏差，超差连续两次一致后更新。
- 学习记录按账号与池隔离并保存在本机；刷新失败、重置和异常不会覆盖可靠旧比例。学习前保留原始百分比，周额度为 0 时 5h 仍为 0。
- 在支持的响应结构中动态发现新增额度池及周期，不再因模型名称不在固定列表而丢弃；未知共享关系的池暂不叠加总量。
- 额度池选择与显示名称编辑分开，下方保留来源名称；账号栏始终显示来源账号名，隐私遮罩仍有效。
- 折叠窗口在尚无已学比例时使用原始额度，取得比例后再自动折算。
- 比例学习静默运行，主界面保持原有紧凑布局，不增加学习状态或比例说明。
- 菜单根据可用空间选择展开方向，避免底部选项被裁切。

本次仅生成本地安装产物，不推送 GitHub、不创建 tag 或 Release。

验证：120 项后端测试、18 项前端测试通过；公开 GitHub 联网检查按默认配置跳过。包含旧版设置迁移回归、名称持久化、动态池解析与比例确认测试。
