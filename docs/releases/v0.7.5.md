# v0.7.5

- 同步上游 Antigravity 云端配额请求 `User-Agent` 为 `aidev_client` 格式，恢复云端回退查询时的 `Gemini` 与 `Gemini 4 Argon` 额度池返回。
- 扩展 Antigravity 额度桶与字段解析：支持 `argon:weekly`、`gemini-argon-*`、`gemini-4-argon-*`、`argon-*` 归入 `Gemini 4` 额度池，并兼容驼峰与下划线字段名。
- 当云端汇总接口省略 `gemini-5h` 时，按需请求 `fetchAvailableModels` 从非内部、非 Argon 的 Gemini 模型中补充 `Gemini 5h` 窗口，不伪造周额度或 Argon 额度。
- 兼容带 UTF-8 BOM 的账号索引与详情文件，本地 Language Server 探测同时支持 `--csrf_token <token>` 与 `--csrf_token=<token>`。

验证：125 项后端测试、18 项前端测试通过；1 项公开 GitHub 联网检查按默认配置跳过。便携 ZIP 与三个发布文件的 SHA-256 校验通过。

下载：Windows x64 安装用户选择 `-setup.exe`；免安装用户选择 `.zip` 或独立 `.exe`。`SHA256SUMS.txt` 提供三个文件的 SHA-256 校验值。
