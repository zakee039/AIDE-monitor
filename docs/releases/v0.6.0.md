# AIDE monitor 0.6.0

## 主题与独立监视屏

- 统一桌面与独立监视屏的主题选择界面：导入主题、横向选择器、大预览和应用按钮；点击主题先预览，点击应用后生效。
- 桌面预览将小窗与悬浮球放在同一行；独立监视屏和桌面主题保持独立的 ID、配色、布局及导入格式。
- “USB 监视屏”统一更名为“独立监视屏”，设备开关和目标屏幕置顶，移除分辨率及冗余说明。
- 独立监视屏自适应屏幕尺寸；四平台横屏四栏、竖屏两行，账号列表按高度调整每页数量。
- 四平台主题显示 ChatGPT、Claude、Antigravity、Grok 各自的总额度，复用桌面悬浮球算法；不可用时中央显示双行恢复倒计时，底部只显示已选账号数量。
- 增加专用 JSON 主题导入及校验，支持账号列表／四平台布局和独立配色。桌面的 `.aidetheme` Widget 包仍使用原有加载方式。
- README 增加作者主页与爱发电链接。

## 升级说明

沿用现有应用标识，保留账号、代理及屏幕选择。旧的共用屏幕主题 ID 重置为独立监视屏的薄荷初音，不与桌面主题建立兼容映射。

独立监视屏支持 Windows 显示设置中可见的显示器；厂商私有 USB 传图设备仍需单独适配。第三方 Widget 应用后在自己的桌面窗口展示。

## 下载

Windows x64：

- `AIDE-monitor-0.6.0-windows-x64-setup.exe`：安装包。
- `AIDE-monitor-0.6.0-windows-x64.exe`：独立运行程序。
- `AIDE-monitor-0.6.0-windows-x64.zip`：便携压缩包。
- `SHA256SUMS.txt`：下载文件校验值。

运行需要 WebView2。源码构建需要 Node.js、Rust 和 Visual Studio C++ 工具链。
