# AIDE monitor 0.3.0

## 变更

新增当前用户开机启动开关；产品名称、托盘、窗口、可执行程序与安装包更名；新增原创 M 发箍 SVG 标志和多尺寸 Windows 图标。常规设置移除重复标题、说明段落与数据源路径；数据源在独立模态窗口管理，支持多选、约定路径发现与选择目录后扫描。账号前显示平台标志，保留上游来源信息。

## 来源兼容

| 来源 | 实现 | 边界 |
| --- | --- | --- |
| 官方客户端 | Codex auth.json；Claude .credentials.json | 本地文件，不访问系统凭据库 |
| Cockpit Tools | codex_accounts、claude_accounts、grok_accounts、accounts 索引及对应详情；AES-GCM v1 | 只读已有 key；不更新 token |
| CC Switch | cc-switch.db providers 表，只读 SQLite 连接 | 识别 OAuth auth / claudeAiOauth 配置；API Key 不代表订阅配额 |
| CLIProxyAPI | 账号 JSON 的 type + access_token | Codex、Claude、Antigravity、Grok；不执行代理配置中的代码 |
| Sub2API | 本地导出 accounts / data.accounts 数组的 platform、type、credentials | OAuth 类型；不连接远程管理 API；账号 ID 或名称用作稳定标识 |

扫描有文件大小、数量、路径边界限制。多个路径指向同一实际目录时去重。所有来源均只读；账号 token 不传入前端或自身设置文件。

## 平台接口

- Codex：保留原有 WHAM usage 适配器。
- Claude：api.anthropic.com/api/oauth/usage，oauth-2025-04-20 header；5h、7d 及模型专用窗口。
- Antigravity：daily-cloudcode-pa.googleapis.com / cloudcode-pa.googleapis.com 的 v1internal:fetchAvailableModels，按已存储 GCP 标志选择；展示 quotaInfo 的模型百分比与 resetTime。
- Grok CLI：cli-chat-proxy.grok.com/v1/billing?format=credits，展示信用额度及产品窗口。

网络固定目标域名，禁止重定向；凭据请求头标记敏感；复用请求超时、响应大小限制和安全错误分类。缺少额度保持未知，模型窗口不推断整个账号可用。Codex 总额度估算不混入其他平台。

## 验证
