# AIDE monitor 0.4.0

本版落实独立 Widget 主题系统。保留三套内置主题，新增 .aidetheme 安装、替换、卸载、主题偏好、独立窗口、aide SDK 和可打包开发模板；移除旧 JSON 主题入口与命令。

新窗口显示前等待 ready，失败/超时自动回退。宿主托盘负责恢复和退出，主题窗口禁止最大化及边缘缩放。切换、卸载撤销会话，独立浏览器数据与安装身份隔离偏好。

主题只读取选中账号的脱敏数据。原生网络过滤、CSP、导航/下载/新窗口限制以及无 capability 的 IPC 边界共同限制可执行主题。相同 ID 替换需确认，安装采用校验后原子提交。

沿用 0.3.1 的 Antigravity Gemini/Claude 5h 与周额度修复、内置 Gemini 显示、账号列对齐以及四项右键菜单。

验证：前端构建、6 项 Node 单元测试、68 项 Rust 单元测试，以及真实 WebView2 合成数据烟测（宿主与主题运行时）。不使用真实凭据发起额度请求。详细结果由 artifacts 中的两份烟测报告生成。

目录与 GitHub 仓库统一为 AIDE-monitor。应用标识保留，以保留现有账号设置；不迁移旧第三方主题。
