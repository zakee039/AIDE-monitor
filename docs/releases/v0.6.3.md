# AIDE monitor 0.6.3

修复刷新失败时独立监视屏的数据展示，并优化错误提示时长。

- 主小窗底部红字提示显示 5 秒后自动消失。
- 刷新失败后继续显示上一轮成功取得的额度数据，汇总统计保留失败账号的历史额度；成功刷新后自动更新。
- 独立监视屏薄荷初音、白昼在账号名前显示“!”；四平台在额度或恢复倒计时前显示“!”。刷新异常不再导致整屏已知数据变为横线。
- 保留仍有效的额度重置倒计时；从未成功取得的数据仍显示未知，不推算重置后的新额度。

验证：11 项前端测试、90 项后台测试通过，1 项联网测试跳过；Windows x64 安装包构建通过。
