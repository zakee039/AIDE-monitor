# v0.7.4

- 独立监视屏窗口改由后台串行任务创建和同步，规避 Windows WebView 在主线程回调中创建窗口的已知卡死风险，避免慢操作期间堆积重复任务。
- 创建窗口后重新核对独立监视屏开关和设备选择，避免切换设置期间显示到已经取消选择的屏幕。
- 增加本机运行诊断：记录启动、正常退出、未正常结束的上次会话、Rust 异常位置、WebView 进程失败和界面无响应。日志自动轮换，不记录账号、凭据、请求地址或异常正文。
- 原生验收增加独立监视屏窗口连续两次创建、加载和销毁检查，全程使用隐藏窗口与隔离的合成来源。
- 增加开发用独立启动脚本，由 Windows 桌面启动本机安装版，避免从开发聊天环境启动时被其退出或切号清理连带结束。

本次切号退出的排查结果是启动关联导致的外部结束；本版本的窗口稳定性与诊断改进不宣称修复该切号行为。

验证：122 项后端测试、18 项前端测试通过；1 项公开 GitHub 联网检查按默认配置跳过。正式构建的原生窗口、独立监视屏重复创建和自定义主题隔离验收通过，便携 ZIP 与三个发布文件的 SHA-256 校验通过。

下载：Windows x64 安装用户选择 `-setup.exe`；免安装用户选择 `.zip` 或独立 `.exe`。`SHA256SUMS.txt` 提供三个文件的 SHA-256 校验值。
