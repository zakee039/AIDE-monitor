# v0.7.1

- Antigravity 本地额度查询前后核对账号邮箱。账号不匹配、身份缺失或切换时回退到目标账号自身的认证查询，避免多账号串额度。
- 已选额度池的过期重置与基础窗口使用相同退避逻辑：30、60、120 秒逐步增加，最高 30 分钟。
- 桌面及独立监视屏的双周期账号，将 5h 剩余额度折算为周额度占比，并受剩余周额度限制。ChatGPT 85% 按 15% 折算显示约 13%；周额度为 0 时 5h 显示 0。
- Antigravity Claude 池默认按 50% 折算，Gemini 3 暂用 25%；独立 Claude 沿用订阅档位估算。自定义比例优先。Grok 和只有周额度的 Gemini 4 不构造 5h 窗口。详见 [比例依据与限制](../quota-ratios.md)。
- 刷新失败或某个窗口未返回时保留历史数值和原始重置时间，以 45% 不透明度显示；成功取得新数据后恢复正常。历史窗口保留原采样时间，不再借用其他窗口的新刷新时间。
- 新增账号隔离、账号切换、指数退避、周额度折算及历史数据恢复测试。自动测试不读取或打印本机真实凭据。
