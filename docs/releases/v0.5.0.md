# AIDE monitor 0.5.0

- 账号行精简为带列头的单行布局，新增独立自动刷新设置，可继承全局、禁止或指定 1 / 5 / 15 / 60 分钟。
- 新增位置锁定，修复悬浮窗和主题展开、收起时的定位闪跳。
- 内置主题更名为 miku mint / 薄荷初音、dark / 黑暗、white / 明亮；移除黑暗、明亮顶部色条。
- 薄荷初音使用三段式伸缩葱分隔线，底栏头像放大至 32px，左、上、下留白约 3px。
- 新增独立 USB 屏幕展示，支持系统识别的显示器、独立内置主题、全屏等比适配和记忆设备断线恢复，不回退到其他屏幕。

USB 实体屏幕拔插仍需实机验证；厂商私有 USB 传图设备需另行适配。
