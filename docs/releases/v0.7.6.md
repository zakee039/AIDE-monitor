# v0.7.6

- 支持只读读取新版 Cockpit Tools 的 SQLite 账号索引（`codex_accounts.sqlite`、`claude_accounts.sqlite`、`grok_accounts.sqlite`、`antigravity_accounts.sqlite`），同时保留对旧版 JSON 索引的回退兼容；跳过过期索引中已删除的单个残留详情条目，并在目录校验时透传真实错误信息。
- 彻底移除 Antigravity 的静态硬编码额度池列表与写死名称，改为完全按服务端返回动态发现、增删池子并原样显示服务端组名（如 `Gemini Models`、`Claude and GPT models`）。
- 增加一次性旧配置迁移清理历史硬编码静态池缓存；放行尚未探测池子的未勾选账号既有别名与选择，修复其他账号额度池重命名保存时误报“额度池名称无效”的问题。

验证：129 项后端测试、18 项前端测试通过；1 项公开 GitHub 联网检查按默认配置跳过。便携 ZIP 与三个发布文件的 SHA-256 校验通过。

下载：Windows x64 安装用户选择 `-setup.exe`；免安装用户选择 `.zip` 或独立 `.exe`。`SHA256SUMS.txt` 提供三个文件的 SHA-256 校验值。
