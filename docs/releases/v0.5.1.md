# AIDE monitor 0.5.1

AIDE monitor（AI IDE monitor）——专业的 AI IDE 订阅额度监视器。

- 新增多组代理配置，名称、地址输入即保存，支持 HTTP、HTTPS、SOCKS5、SOCKS5H；账号可独立选择，默认为系统。
- 代理删除后自动解除账号关联。无效地址或连接失败会报错，不回退到其他网络路径。
- 修复已耗尽窗口与服务端许可标记不同步造成的恢复推荐漏选。5h < 5%、7d < 2% 表示不可用；只等待不足窗口，底栏及圆窗共用最早恢复结果。
- 截图场景（0% / 23% 在 1h01m 后重置，与 2% / 69% 在 2h11m 后重置）会推荐前者。
- 关于页增加 GitHub Releases 更新检查、版本说明及下载入口，更新产品介绍。
- 删除 USB 屏幕设置状态行，修正 available 拼写。

更新检查使用系统网络设置，比较正式版语义版本号，下载由 GitHub 发布页完成。
