# Chatgpt HUD v0.2.3 · Prototype

A compact quota HUD built with Tauri 2 and Rust. This release captures the current prototype after the HUD layout and quota orb refinements.

- Fold the HUD into a draggable 43 × 43 circle; click it to expand. The circle displays the combined quota estimate, including totals above 100%.
- Larger 16px circle text. When known quota is exhausted, the earliest usable countdown appears on two centered lines, such as `3H` / `16M`, or days / hours for longer waits.
- Align account names, quota percentages, separators, countdowns and reset credits across rows, with four-character spacing between logical columns.
- Size the expanded window to its content. Weekly-only accounts omit the 5-hour limit; weekly limits stay aligned when different account types are shown together.
- Align the footer text and share the same layout and interactions across all three built-in themes.
- Add `totalQuota` to `quota.snapshot.get`. Dual-limit accounts contribute `5hRemaining × min(weeklyRemaining / 15, 1)`; weekly-only accounts contribute their weekly remaining percentage. The 15% factor is a local HUD estimate, not an official OpenAI conversion. Unknown, failed or stale data is omitted and marked as partial in the API.

Windows x64 downloads: the `.exe` runs without installation; the `-setup.exe` installs the app. WebView2 is required. `SHA256SUMS.txt` contains checksums for both files.

Validation: production build and native WebView/IPC checks passed, including fold/expand, 16px text, settings reopening and tray pinning at 250% system scaling. Browser previews verified column alignment, weekly-only layouts and centered countdowns using fictional data.
