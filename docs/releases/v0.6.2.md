# AIDE monitor 0.6.2

优化独立监视屏在不同账号数量下的布局。

- 独立监视屏薄荷初音、白昼的单账号布局：顶部图标与账号名，下方两项额度及重置时间左右并排。
- 双账号布局：上下各一行，左侧图标和账号名，右侧并排展示两项额度与对应重置时间。
- 三四账号保留原有竖列布局，超过四个账号每 8 秒横向滑动一页；竖屏继续自适应。
- 保留长名称省略、黑色倒计时及主界面额度颜色分级。四平台主题及总额度算法不变。

## 下载

Windows x64，运行需要 WebView2，升级保留现有账号与设置。

- AIDE-monitor-0.6.2-windows-x64.exe：独立运行程序。
- AIDE-monitor-0.6.2-windows-x64.zip：便携包。
