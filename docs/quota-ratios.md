# 额度池与自动换算比例（v0.7.3）

所有平台使用同一套比例学习算法，不再按平台、订阅或旧自定义设置套用固定 5h／7d 比例。订阅倍率仍用于不同档位的总量估算，与周期换算比例分开。

## 学习与确认

- 按物理账号和稳定额度池 ID 隔离样本、候选比例和已采用比例；更改显示名称不会重建学习记录。
- 只采纳成功取得的同次网络响应中，具有有效重置时刻的 5h 与 7d 原始百分比。缓存、保留的历史窗口、失败响应、时间倒退不作为新证据。
- 每次刷新从 n−1、n−2、n−3 向前查找，同一重置周期内 5h 下降至少 **50 个百分点**的最近样本。比例 = 周额度下降百分点 ÷ 5h 下降百分点。
- 80/90 → 60/80 → 20/60 时，最后一次回溯到 80/90，得到 30/60 = 50%。首次有效比例立即采用。
- 已有比例允许 **绝对 ±2.1 个百分点**误差。容差内保留旧值；超出容差的候选必须在连续两次有效刷新中彼此落在该容差内，才采用最新值。例如 30% → 28% → 20% → 20%，采用值为 30% → 30% → 30% → 20%。
- 缺少有效候选会中断连续确认；周期重置或任一余额回升会清空该周期样本。0% 可能已经被截断，不能用来训练比例。可靠旧比例继续保留，等待新证据。
- 每个池最多保留 512 个不同余额对，全局最多 100,000 个样本；超额优先清理最久未观察的样本，保留其已学比例。记录持久化在本机设置中。

这种方法估计的是观察时段中的消耗关系。其他模型共用周池、平台统计延迟或消费结构变化仍可能影响估计，因此学习状态仅保留在后台接口中，主界面不显示学习状态或换算比例，只展示额度和恢复时间。

## 显示

5h 显示值为 `min(原始 5h 百分比, 剩余周百分比 ÷ 已学比例)`，保持 5h 自身单位；两个窗口满额显示 100%，周额度为 0 时 5h 也为 0。尚无比例时展示原始窗口值，不填入固定比例。原始测量不修改。

圆形悬浮窗和独立监视屏由 `quota_total::calculate` 统一计算；尚未学到比例的双周期账号直接使用原始 5h 余额参与展示；混合纯周账号但暂无参考比例时使用其原始周余额，不填入固定比例。只有周额度时直接展示周额度单位。无法确认是否独立计量的新池不重复累加进总量，但可独立展示和学习。

刷新失败或某窗口缺失时保留旧数值与原始重置时间，按 45% 不透明度显示；新测量恢复后正常显示。历史数据显示不恢复当前账号的推荐资格。

## 发现与命名

在支持的响应结构中，Antigravity 从桶标识、周期后缀和显式周期长度发现新池，Claude 接收新增利用率对象；未知名称使用稳定 ID 保存。周期无法识别时保留为未知，不伪造 5h。上游更改认证、字段含义或响应结构仍需要更新适配器，不能保证任意未来协议自动兼容。

额度池选择器左侧勾选，右侧编辑显示名称，下方保留来源名称；点击“保存选择”提交。账号栏始终展示来源账号名，账号别名只影响额度展示；隐私模式仍遮罩身份。
