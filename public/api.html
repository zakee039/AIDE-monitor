Chatgpt HUD · 0.2.3 · API 1.0

API reference / 接口说明

These methods are available to the app's trusted Tauri windows. Version 0.2.3 does not expose an HTTP server or grant external webpages access. Themes are validated JSON data, not executable plugins.

这些方法通过应用内 Tauri 接口向受信任窗口提供。0.2.3 尚未开放 HTTP 服务，外部网页不能直接调用。主题为经过校验的 JSON 数据，不执行插件代码。

Call a method / 调用方法

import { invoke } from '@tauri-apps/api/core';
const result = await invoke('hud_v1_quota_snapshot_get', { request: {} });
if (result.ok) console.log(result.data.recommendation);
else console.error(result.error.code);

// Logical names map to hud_v1_ + dots replaced by underscores.
// accounts.alias.update → hud_v1_accounts_alias_update

Responses contain apiVersion, requestId, instanceId, revision, generatedAt, ok and either data or error. Revision numbers are only comparable within one instanceId. Query capabilities first; the settings window has 17 public methods, the HUD has 9.

返回值包含 apiVersion, requestId, instanceId, revision, generatedAt, ok，以及 data 或 error。revision 仅在同一个 instanceId 内可比较。先查询 capabilities：设置窗口提供 17 个公开方法，HUD 提供 9 个。

Estimated total / 估算总额度

snapshot.totalQuota = {
  percent: 52,             // null if no reliable balance is known
  partial: false,          // true when selected accounts are excluded
  weeklyScalePercent: 15   // local heuristic, not an official conversion
};

Dual-limit accounts contribute H × min(W / 15, 1); weekly-only accounts contribute W. H and W are remaining percentages. Totals may exceed 100%. Stale, failed and unconfirmed samples are excluded. Recommendation floors (5h ≥ 5%, weekly ≥ 2%) are separate. The folded HUD displays the earliest usable countdown when the complete, known total is zero.

双限额账号贡献 H × min(W / 15, 1)，单周限额账号贡献 W；H/W 为剩余百分比，总量允许超过 100%。过期、失败、等待核实的数据不计入。推荐阈值（5H ≥ 5%、周 ≥ 2%）单独计算。完整可信总量为零时，折叠圆球显示最近可用倒计时。

});
// Call stop() when the view is disposed.

snapshot.changed · refresh.progress · refresh.completed · source.changed · settings.changed · theme.changed · resync.required

Events are invalidation notices. Re-read authoritative data; subscribe before the first read. On a changed instanceId or resync.required, fetch a new snapshot. Settings writes use optimistic concurrency: on CONFLICT, reload before retrying. Alias updates affect only one alias and do not change account selection.

事件用于通知数据失效，应重新读取快照；首次读取前先订阅。instanceId 变化或收到 resync.required 时重新同步。设置写入使用乐观锁，遇到 CONFLICT 需重新读取。别名接口只更改单个别名，不更改账号选择。

Accounts & quota / 账号与配额

Only ChatGPT sign-ins are imported; API-key entries are excluded. Automatic discovery checks CODEX_HOME/auth.json (default ~/.codex/auth.json), then Cockpit Tools. OS keyrings and memory-only credentials are not supported. isCurrent means the identity in the selected official auth file at the last scan; it does not identify every open chat's active account. Rescan after switching accounts. Source files are never modified; sign in again in the original app when authentication expires.

仅导入 ChatGPT 登录账号，排除 API Key。自动发现优先检查 CODEX_HOME/auth.json（默认 ~/.codex/auth.json），然后检查 Cockpit Tools。暂不读取系统凭据库或仅内存凭据。isCurrent 仅表示上次扫描时官方文件保存的账号，不代表每个已打开会话的账号。切换账号后请重新扫描。源文件只读，凭据过期时请在原应用重新登录。

Recommendation requires at least 5% in the 5-hour window and 2% in the weekly window. Unknown or stale data is not treated as available. R is the reset credits reported by the upstream service, not a locally counted number of resets.

推荐当前可用账号要求 5 小时剩余额度至少 5%、周额度至少 2%；未知或过期数据不会当作可用。R 是上游报告的可用重置次数，不是本机累计计数。
